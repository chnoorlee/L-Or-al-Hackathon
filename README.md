# 匀色遮瑕助手

[打开匀色遮瑕工作室](https://chnoorlee.github.io/L-Or-al-Hackathon/) · [部署与手机使用说明](docs/browser-preview-access.md)

网站由 GitHub Pages 托管，推送到 `main` 后自动检查、构建并部署；不依赖本机或临时隧道保持在线。微信小程序源码继续保留在 `miniprogram/`。

浏览器版面向白癜风与局部肤色差异人群，提供自主选择的遮瑕预览。默认流程是「选择皮肤照片 → 点选想遮盖的位置 A 与周围参考肤色 B → 修整选区 → 调整遮盖程度」。支持面部、手部、手臂等照片，提供补涂、擦除、加选相似区域、撤销、强度与边缘微调、原图/分屏对比和图片保存。

保留端侧 MediaPipe 与 WebGL 面部实时预览，可叠加全脸底妆和眼下遮瑕。任意皮肤斑块使用照片局部遮瑕；浏览器当前不提供身体斑块实时追踪。产品区聚焦 7 款底妆/遮瑕产品与 155 个公开色样，可选用商品色样或恢复 B 参考色。色样未标定到实物显色，「相近色样」不是肤色匹配推荐。其他彩妆数据和渲染能力保留在底层，不再作为当前网页的主入口。

```powershell

```

电脑打开 `http://localhost:4173`。手机相机必须通过 HTTPS 打开；普通局域网 HTTP 地址不能用于 iPhone 相机验收。生产文件在 `dist/web`，静态服务仅开放这个目录。开发时用 `npm run web:dev`。当前界面、流程与验证边界见 [局部遮瑕工作室 v0.7](docs/browser-cover-v0.7.md)，原实时引擎记录见 [v0.6](docs/browser-tryon-v0.6.md)。浏览器的收藏只保存商品色号，不保存照片或取样肤色。以下内容描述原有小程序。

微信原生小程序，提供照片局部试妆、摄像头局部遮瑕和自动人脸试妆。自动模式接入微信 VisionKit 106 点人脸定位，支持叠加底妆、唇色、腮红，并提供分屏与按住原图。局部模式由用户点选待遮盖处 A 和周边参考肤色 B，辅助圈选、修边，再探索妆效。当前是需要真机验收的原型。

这是颜色选区与视觉渲染原型，不是白癜风诊断模型，也未校准到真实化妆品的覆盖力或色号。生产商品目录保持为空，不生成虚构 SKU 或购买入口。

## 使用流程

- 照片：在手机微信中打开预览 → 首页“拍一张照片”调用当前手机相机，拍摄确认后进入取样（也可从相册选择）→ 点选 A、B → 自动圈选并试妆 → 补选、涂抹或擦除 → 确认轮廓 → 比较轻薄底妆、局部遮瑕、柔焦底妆；优先调节强度和左右对照分界线，展开“精细微调”可调冷暖、明度与边缘柔化。
- 人脸试妆：首页“打开实时试妆镜” → 主动开启前置相机并授权 → 脸部完整入镜 → 选底妆、唇色、腮红并分别调节或移除。无需 A/B 取样；定位过期、多人或无法定位时撤妆。真实定位需要支持 VisionKit 的手机微信。
- 局部遮瑕：实时页切换“局部遮瑕” → 定格 → 点选 A、B → 确认轮廓 → 实时试妆。可换妆效、相对色调、强度，分屏或按住看原图。短暂丢失撤妆，连续两次稳定检测后恢复；未找回则重新圈选。两种模式退出或切后台均关闭相机、清除本次帧与选区。
- 结束：照片试妆页“完成并清除本次图片”。原有取样结果仍可通过取样页“查看取样结果”进入。

## 数据边界

- 不注册、不登录，不建设用户画像、服务端或交易后台。
- 照片、相机帧、选区、色值和结果只存在于当前内存会话；代码不调用上传或持久化接口。
- 普通照片固定标记为 `uncalibrated`，不会仅凭目录中的 LAB 值获得可比资格。
- 真实商品、官方路由和病灶分割模型均未提供；局部圈选是颜色算法。人脸模式使用微信原生定位能力，不把人脸关键点称为白癜风识别，也不报告未经测量的准确率。

照片预览最长边为 640 像素。实时局部模式由 WebGL 合成原始相机帧，分析图最长边 256；显示和区域分析按至少 33 / 66 毫秒限流。人脸模式单次只提交一帧分析，保留与关键点对应的最长边 640 帧进行合成，250 毫秒后定位失效。WebGL 不可用时，局部模式可用 Canvas 2D，人脸模式提示切换局部遮瑕。这些是实现参数，实际手机帧率尚未测量。五分钟无操作清除会话/停止相机；系统临时缓存不承诺物理擦除。

## 界面与辅助预览

五页使用雾白背景、梅子主色、墨紫文字和浅藕灰分组，保留金色轮廓与 A/B 语义。人脸实时页按“品类 → 色盘 → 浓度/质感”组织控件，允许独立叠加和移除；镜面等比例缩放并在滚动换色时保持可见。设计参考与边界见 [视觉方向](docs/visual-direction.md)，历史检查见 [界面验证记录](docs/ui-validation-2026-10-16.md)。未经欧莱雅官方设计审核。
