# 浏览器局部遮瑕工作室 v0.7

日期：2026-10-18。网页重新聚焦白癜风与局部肤色差异人群的自主遮瑕预览；保留原有微信小程序和浏览器实时引擎。

## 产品与界面

- 默认进入「照片局部遮瑕」，将彩妆品类商城式入口改为「选照片 → 圈选与取色 → 看遮瑕效果」。可以遮盖，也可以保留，页面不把肤色差异描述为必须修复的问题。
- 雾白、浅紫与深紫组成工作区，A/B 图示解释取样；图示明确标注并非真实遮瑕效果。桌面双栏，手机选图后固定预览、独立滚动设置，调整参数时仍能看到照片。
- A 是想遮盖的位置，B 是附近希望参考的肤色。按颜色辅助圈选后，可补涂、擦除、加选分离区域、撤销或清空。用户确认选区后才进入效果预览。
- 预览默认使用 B 参考色，只修改选区。提供轻透、匀色遮盖、柔和纹理、强度、边缘柔和度、冷暖和明度，以及原图/分屏对比和 PNG 保存。
- 产品区为可选步骤，展示现有公开目录中的 7 款底妆/遮瑕产品、155 个色样。选择商品色样后可一键恢复 B；相近色样采用 RGB 距离，明确不等同于标定配色或推荐购买。
- 实时入口保留单人全脸底妆、眼下遮瑕及叠层、换色、原图/分屏比较和保存，使用既有端侧定位与 WebGL 管线。当前眼下遮瑕为固定面部区域，不声称能实时追踪任意皮肤斑块。

## 实现与数据边界

`web/src/local-cover.ts` 适配小程序中既有的颜色选区与像素渲染引擎，未增加疾病识别模型。共享引擎增加可选目标 RGB 参数，原调用不传参数时保持 B 参考色行为。照片最长边缩放至 640 像素，输入限制为 20 MB，画布坐标排除等比显示产生的留白。

照片仅在内存处理。关闭预览、切换模式或离开页面会清除当前图像、取样、选区和导出链接；切后台停止实时相机。只有主动保存才生成本机 Blob 下载链接。收藏持久化商品色号，不保存照片或取样颜色。系统级缓存不承诺物理擦除。

## 本地验证

- `npm run verify`：类型检查及 211 项测试通过，覆盖共享渲染回归、商品目标色与 B 色切换、照片坐标映射等。
- `npm run web:build -- --base /L-Or-al-Hackathon/`：网页类型检查和生产构建通过。
- 浏览器生产包使用 400×500 的合成双色图完成 A/B 取样、自动圈选、擦除和撤销、确认、强度、分屏、商品色样切换、恢复 B 和图片导出检查。
- 合成图中 A 为 RGB(228,202,183)，B 为 RGB(163,119,94)。默认 78% 匀色遮盖时，选区内部检查点变为 (180,143,121)，区外检查点保持 (163,119,94)；0% 恢复 A，100% 的分屏左右分别显示 A 与 B。该记录验证像素功能，不代表真人或商品效果。
- 擦除检查点从紫色选区覆盖 (182,156,183) 恢复原图 (228,202,183)，撤销后恢复覆盖。导出图尺寸为 400×500，使用本机 Blob 链接。
- 390×844 手机尺寸下无横向溢出；确认选区后设置面板自动回到顶部。切换实时模式后，照片画布检查点清为透明，导出地址被移除。

这些是桌面浏览器响应式与合成图检查，不是本轮 iPhone 真机验收、临床验证或实际商品遮盖力验证。真实肤色、光照、复杂斑块和手机性能仍需设备实测。
