# 商品目录准入

生产条目必须同时具备真实产品身份、来源记录、有效颜色证据和明确适用范围。缺少购买路由只会关闭购买入口；缺少产品身份或必需颜色证据会禁止进入候选。

## 最小审查清单

- 品牌、产品 ID、SKU ID、色号编码、色号名和完整产品名可从权威来源核对。
- 图片具有明确的使用许可，不以包装渲染色或网页显示色替代实物色样。
- `colorEvidence` 区分网页显示色、实物色样和干燥成妆色，不混排。
- LAB 数据记录测量协议、比较组、采集设备/有效转换、证据引用和适用范围。
- `verifiedAt` 是实际核验日期；库存只表述为“信息核验于该日期，以商城为准”。
- 重复 SKU、空 LAB、异常数值、协议编号孤证均不得进入精确排序。
- 官方路由单独记录 AppID、路径、参数协议和双端真机证据；成功回调不算落地验证。

生产目录位于 `miniprogram/data/catalog.production.ts`。在上述资料齐备并复核前，该数组必须保持为空。
