# 演示脚本

当前版本包含照片即时试妆和摄像头跟踪原型。妆效以周边取样颜色为基础，三种效果模板尚未与真实商品校准；辅助圈选是颜色算法，不判断白癜风。真实色号排序与官方购买仍未接入。

## 照片试妆

1. 用手机微信扫描预览码，首页介绍照片与实时两种方式，说明照片仅在本机处理；需要时展开“第一次使用？”查看三步指南。点击“拍一张照片”，用当前手机拍摄并确认后进入取样；也可从相册选择已获授权的演示图片。
2. 点选 A“待遮盖处”，观察自动引导切到 B，再点希望接近的周边肤色。
3. 展开“微调范围与位置”，用方向按钮移动 B 或调整范围；点击“撤销上次”恢复。它只撤销最近一次取样调整，不是图片历史。
4. 点击“自动圈选并试妆”，展示算法生成的金色轮廓。解释 A 是待覆盖区域、B 是参考肤色；轮廓需要用户确认。点另一块区域可补选，涂抹/擦除可修正，撤销可恢复最近一次选区操作。调整容差会重新圈选。
5. 确认选区后切换轻薄底妆、局部遮瑕、柔焦底妆；调整强度、冷暖、明度与边缘柔化。用“左右对照”移动分界线，并切回原图核对。说明它展示的是模拟妆效，不代表某款产品实测。
6. 如需核对取样，返回 A/B 页再点“查看取样结果”；展示实际取样颜色以及“商品色号尚未接入”。质量提示只按真实像素结果展示。
7. 点击“完成并清除本次图片”返回开始页，说明应用清理本次持有的数据；微信或系统缓存不保证立即擦除。

## 摄像头试妆

1. 首页点击“打开实时试妆镜”，或使用照片工作室的实时试妆入口；由演示者主动开启相机并完成权限授权。若没有实际帧数据，展示错误状态，不将静态图称为实时画面。
2. 在稳定光线下取景，定格画面后点 A 待遮盖处、B 周边参考肤色；确认金色轮廓，再开始跟踪。
3. 缓慢、小幅移动目标，观察下方处理画面随帧更新。切换效果模板、遮盖强度和原图开关。取景小窗只供构图，妆效显示在独立处理画面中。
4. 演示重新校准；验收时测试遮挡、快速移动、光线变化与相似背景。系统判定跟踪丢失时撤去妆效并要求重新校准，未捕获的误跟踪必须如实记录。
5. 关闭相机或离开页面，确认停止取帧并清理画面。返回页面不自动打开相机。

本脚本须在目标设备验收后用于现场实时演示。原生模拟器中的照片流程使用合成 PNG；实时管线检查使用注入的合成连续帧，均不代表以上流程已在真机通过。
