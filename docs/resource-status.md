当前对外表述为“本地虚拟试妆原型，含照片模式和摄像头实验模式”。照片原图、应用内存及相机帧不上传、不主动保存；合成插画只用于开发检查，不代表真人效果或模型能力。

同步像素计算不能被 JavaScript 定时器抢占。尺寸限制和帧限流用于控制计算规模，目标设备的响应、处理耗时和长时间稳定性仍须实测。自动人脸模式使用二维关键点蒙版与帧间纹理跟踪；未实现头发/手部遮挡分割、三维材质或实物色号校准，不能据本地测试宣称达到参考商业产品的效果。详见 [v0.5](realtime-tracking-v0.5.md)。
