## 已修改

- 五页统一雾白背景、梅子色主按钮与浅藕灰分组；中文标题使用系统无衬线，色值使用等宽字体。此次参考 Dribbble 美妆设计的展示层级与操作分组，来源及转化见 [视觉方向](visual-direction.md)，不宣称通过品牌官方设计审核。
- 首页改为原创肤色镜面插画、一个实时试妆主入口、两个并列照片入口。新手指南默认收起，按需展开三步说明；隐私和模拟边界始终可见。
- 拍照按钮为“拍一张照片”，下方说明手机微信直接调用这部手机的相机，拍摄确认后进入取样；原有拍照及相册处理逻辑保留。
- 照片工作室优先展示镜面、对比切换、三种妆效和强度；冷暖、明度、边缘柔化与轮廓开关收入“精细微调”。原生点击展开、收起后，选定妆效与强度不被重置。
- 照片预览状态移到画布外，避免被原生画布遮挡。首页和实时关闭状态复用原创 SVG，并注明是色彩概念插画；没有复制参考作品的人像或商品。
- 取样 A 使用虚线、B 使用实线，保留字母和文字。圆框内部透明，图片与实际色块不添加美化滤镜。
- 结果页放大两处实际颜色，清楚区分取样结果、商品尚未接入与结束清理操作。
- 修复 320 像素宽度下“撤销上次”点击区域不足 44 像素；文字按钮统一最小触控尺寸。
- 修复大字体下缩放比例与“＋”按钮挤压，允许标题与缩放工具换行；调大关键色值与辅助标签。
- 新增试妆工作室，按“确认选区 → 探索妆效”分步展示；提供补选、涂抹、擦除、撤销、三种妆效模板与原图对照。
- 摄像头页面 v0.3 使用单一大幅试妆镜；原生相机位于处理画布下方，画布按帧宽高比显示。增加即时相对色调、分屏、按住原图和收起的精细调节；镜头方向与触点仍需真机验收。
- 修复原生画布遮挡：翻转与对比控件移至画布上下，圈选圆环绘入显示像素且不污染取样源；关闭后隐藏未使用画布，空状态文字恢复可见。三种状态均已核对原生截图。
- 试妆与摄像头按钮适配小屏和大字体，控制区可换行；修复 WXML 条件表达式转义和 WXSS 不支持的通配选择器。
- 原生截图中发现 A/B 圆框下方的说明挤压图片，移除重复浮动说明；保留圆框字母、下方完整操作标签及辅助朗读名称。
- 相机权限请求增加等待状态、防重复点击和 10 秒超时恢复；迟到的授权回调不能重新打开已关闭的相机。
- 实时页默认人脸试妆，按底妆、唇色、腮红分区控制，支持独立叠加/移除、概念色、浓度与唇部质感；保留局部遮瑕切换。定位不可用时提供直接切换局部遮瑕的入口。
- 人脸镜面保持相机帧比例，高度不超过可用窗口的 42%，滚动换色时吸顶；分屏触点使用实际显示尺寸。新增短屏底妆、唇色、腮红检查，避免竖向相机画面挤走色盘。
- v0.5 将视频刷新与定位分开；定位期间对照栏保持位置、暂时禁用，状态区预留高度，减少控件跳动。定位丢失会释放按住原图状态，恢复后可继续显示妆效。

## 通过的检查

| 检查 | 结果 | 证据边界 |
| --- | --- | --- |
| `npm run verify` | TypeScript 通过；19 个文件、208 项测试通过 | 算法测试使用合成像素/关键点，页面处理逻辑使用模拟微信桥接，不代表微信客户端运行 |

辅助排版范围包括：入口、展开指南、授权说明、出错和忙碌状态；取样初始/已选/展开微调/分析中；结果默认/图片展开/曝光提示/已清理；试妆圈选/妆效/展开精细微调；摄像头关闭/跟踪/丢失/展开精细微调，以及人脸唇色、腮红、定位不可用状态。检查宽度 320、375、430 像素，另有根字号 32 像素的布局及 320×568 小屏。普通布局根字号为 16 像素；此项不等于微信系统字体设置的真实行为。

脚本检查可见元素是否横向越界、按钮是否至少 44×44 像素、文字是否横向挤出容器，并验证样式变量是否有定义。主页面、小屏大字体、微调区域、授权说明经截图人工检查；未做真实用户可用性研究。原生拖动、缩放、焦点、读屏、权限、EXIF 和颜色表现仍待微信环境验证。

预览图片与色值是显式标记的合成布局夹具，试妆像素由本项目实际算法生成。夹具只存在于开发脚本及 `.artifacts/`，不进入 `miniprogram/`，不代表真实照片、肤色、商品、匹配精度或遮盖效果。HTML 预览是静态排版，按钮不调用微信接口，摄像头窗口为占位布局。

## 重现预览

```powershell
npm ci
npm run verify
npm run check:wechat
npm run review:ui
```

默认使用已安装的 Microsoft Edge，不自动下载浏览器。Chrome 可用 `$env:UI_BROWSER_CHANNEL='chrome'` 指定。输出位于 `.artifacts/ui-review/`：`overview.png` 展示首页、照片试妆与摄像头布局，各状态有 PNG/HTML，`report.json` 记录尺寸与检测项。所有输出均标明辅助预览，并明确 `nativeWeChatValidated: false`。独立编译器报告位于 `.artifacts/wechat-compile/report.json`。最终首页、展开指南和实时关闭状态的独立原生截图位于 `.artifacts/native-design/`。
