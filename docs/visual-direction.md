## 产品逻辑

首页从“阅读操作说明”转为“选择一种试妆方式”。主入口是实时试妆镜；拍照与相册并列在其下，均直接进入原有照片取样流程。手机微信的拍照按钮调用该手机相机。新手指南默认收起，隐私和模拟边界始终可见。

照片流程仍是：选图 → A/B 取色 → 确认并修正选区 → 探索妆效。选区确认前不把用户直接放进调色面板。妆效阶段优先呈现三种模板和遮盖强度，冷暖、明度、边缘柔化与轮廓开关放进“精细微调”。展开、收起不会重置妆效。实时页默认自动人脸试妆，按品类、色盘、浓度探索底妆/唇色/腮红，各层独立叠加或移除；局部遮瑕另保留定格取色、轮廓确认、跟踪、丢失撤妆。镜面保持当前上下文，换品类不重置已选妆容。

真实色号尚未接入，因此三个按钮表达的是模拟效果模板；不把它们包装成真实品牌商品，不增加虚假购买、销量、肤质诊断或 AI 精准匹配标签。

## 视觉语言

- 雾白背景 `#F9F7FA`、墨紫文字 `#292332`、梅子主色 `#78475F`、浅藕灰分组 `#EEE5EC`。主色表示可操作项和当前选择。
- 金色轮廓与 A/B 的颜色、字母、线型继续承担取样语义。实际取样色块不添加渐变、滤镜或半透明美化。
- 中文使用 PingFang SC / Microsoft YaHei / sans-serif；品牌用疏朗大写 Arial，颜色数据用等宽字体。没有下载或冒用授权字体。
- 首页原创“肤色镜面”SVG 是项目自己的概念插画，明确标注，不是真人照片、算法识别结果或效果证明。妆效按钮的小笔触仅作类别识别。
- 主按钮约 48px 高，控件有明确选中态与 140–150ms 按压反馈；打开指南按需显示，尊重减少动态效果设置。
- 镜面保留真实画面宽高比。状态说明放在画布外，避免原生画布层级遮挡。

## 自评与验收边界

此前的页面主要问题是说明堆叠、三个入口同等抢眼、调节参数过早出现，首屏更接近工具说明。此次把用户第一步和后续决策缩短到“选方式 → 确认区域 → 试妆”，同时用原创镜面图形与统一控件建立识别。

这是基于现有产品任务的设计判断，尚未经过真实用户可用性研究，不能据此声称转化率或满意度提升。照片与实时相机的采集、算法与隐私边界没有因视觉升级而获得额外验证。测试、辅助布局与微信原生验证分别记录于 [界面验证记录](ui-validation-2026-10-16.md) 和 [原生调试记录](native-validation-2026-10-16.md)。
